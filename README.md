# 🛒 Продукты для всей семьи

Веб-приложение для управления семейными покупками. Создавайте свой каталог товаров, добавляйте необходимое в избранное и легко управляйте списками.

## ✨ Возможности

- **📁 Просмотр каталога**: Адаптивная сетка карточек товаров с изображениями, ценами и описаниями.
- **⭐ Избранное**: Отмечайте важные товары звездочкой для быстрого доступа.
- **➕ Добавление товаров**: Простая форма для внесения новых позиций в каталог.
- **🗑️ Управление**: Удаляйте ненужные товары в один клик.
- **🔍 Поиск и фильтрация**: Быстрый поиск по названию и фильтрация по категориям.

## 🛠 Технологии

Проект построен на современном стеке:

- **⚛️ React** + **TypeScript** — для надежных и предсказуемых интерфейсов
- **🚀 Vite** — сверхбыстрая сборка и development-сервер
- **🎨 Ant Design** — красивые и готовые UI-компоненты
- **🔄 Redux Toolkit** — централизованное и простое управление состоянием
- **🛣️ React Router Dom** — навигация между страницами

## 📡 Источник данных

Данные о товарах загружаются с публичного **Fake Store API**:  
[https://fakestoreapi.com](https://fakestoreapi.com)

> **Примечание**: Для стабильной загрузки изображений с API рекомендуется использовать VPN.
